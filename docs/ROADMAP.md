# Roadmap

## v1 — Vertical slice

- Meniu funcțional, Overgrown Approach, mișcare completă, Mossling FSM, melee/ranged, damage, pickups, checkpoint, respawn, salvare, HUD, pause, settings, particule și parallax.

## v2 — Content complete

- Completează cele cinci biome, nivelurile și arenele declarate.
- Implementează boss fights, hazard-uri, treasure zones, unlock-uri, inventory complet și toate ramurile skill tree.
- Adaugă soundtrack și SFX originale.

## v3 — Polish

- Gamepad support și accessibility presets.
- Challenge mode, time trials și New Game+.
- Localizare, PWA/offline mode și integrare opțională cu cloud save.
- Editor intern de niveluri pentru echipa de conținut.

## Lansare comercială

- QA cross-browser, tuning de performanță, balansare finală, pagină de store și pachete etice opționale: soundtrack, expansions și cosmetics originale.
